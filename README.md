# Бот для школьного чата

Бот хранит домашние задания и конспекты по предметам, вместе с фото и файлами.

Нужен Python 3.11 или новее.

## Запуск

1. Создай бота в [@BotFather](https://t.me/BotFather) и скопируй токен. Командой `/setprivacy` выбери Disable, чтобы бот видел сообщения в группе. Можно вместо этого назначить бота администратором группы.
2. Скопируй `bot/.env.example` в `.env` в корне проекта и вставь токен.
3. Установи зависимости:

```
pip install -r bot/requirements.txt
```

4. Запусти бота из корня проекта:

```
python -m bot.main
```

Добавь бота в группу класса от имени администратора группы. Этот человек получит роль admin.

## Команды

- `/start` - главное меню
- `/дз` - смотреть записи
- `/добавить` - новая запись, для администратора и редактора
- `/предметы` - список предметов
- `/добавить_предмет Название` - создать предмет, только администратор
- `/удалить_предмет Название` - удалить предмет, только администратор
- `/редактор @username` - назначить редактора, только администратор
- `/убрать_редактора @username` - снять роль редактора, только администратор

Редактор может добавлять и менять записи и вложения. Обычный участник может только смотреть.
